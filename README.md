# DocBot — Telegram-бот для самозанятых

Telegram-бот на PHP для самозанятых (НПД). Генерирует договоры оказания услуг и акты сдачи-приёмки в PDF.

## Возможности

- Регистрация самозанятого (ФИО, ИНН, банковские реквизиты)
- Создание договоров оказания услуг (PDF) с подтверждением
- Создание актов сдачи-приёмки (PDF) с подтверждением
- Поддержка 3 типов заказчиков: физлицо, ИП, юрлицо
- Управление клиентами (добавление и удаление)
- Редактирование своих реквизитов
- Экспорт документов в CSV
- Бесплатный тариф: 3 документа в месяц
- Уведомления об истекающих договорах (cron)
- Быстрый выбор дат (Сегодня / +30 / +90 дней)
- НДС не облагается (422-ФЗ)

## Требования

- PHP 8.1+
- MySQL 5.7+ / MariaDB 10.3+
- Composer
- SSL-сертификат (для webhook Telegram)

## Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/your-user/docbot.git
cd docbot
```

### 2. Установка зависимостей

```bash
composer install
```

### 3. Настройка конфигурации

```bash
cp config.example.php config.php
```

Отредактируйте `config.php`, указав:
- `bot_token` — токен вашего бота от @BotFather
- `webhook_url` — URL вашего сервера (например, `https://your-domain.ru/index.php`)
- `db_host`, `db_name`, `db_user`, `db_password` — данные подключения к MySQL

### 4. Создание базы данных

```bash
mysql -u root -p your_database < install.sql
```

Или выполните SQL из файла `install.sql` через phpMyAdmin.

### 5. Установка webhook

Выполните в браузере или через curl:

```
https://api.telegram.org/bot<YOUR_TOKEN>/setWebhook?url=https://your-domain.ru/index.php
```

### 6. Проверка

Напишите боту `/start` в Telegram.

```
storage/
  pdf/                 — сгенерированные PDF-файлы

```

## Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Начало работы / регистрация |
| `/menu` | Главное меню |
| `/mydata` | Просмотр/редактирование реквизитов |
| `/export` | Экспорт всех документов в CSV |
| `/cancel` | Отменить текущее действие |
| `/deletedata` | Удалить все свои данные |
| `/help` | Справка |

## Админ-команды

Доступны только пользователю с `admin_telegram_id` из `config.php`.

| Команда | Описание |
|---------|----------|
| `/admin` | Полная статистика: пользователи, документы, финансы, график по дням, топ-5 пользователей |
| `/broadcast` | Рассылка сообщения всем пользователям (с превью и подтверждением) |
| `/grant @username` | Выдать подписку PRO на 1 месяц |
| `/grant @username 3` | Выдать подписку PRO на 3 месяца (1–12) |
| `/revoke @username` | Отозвать подписку |

## Нумерация документов

- Договор: `ДОУ-YYYYMMDD-NNN` (например: ДОУ-20260330-001)
- Акт: `АКТ-YYYYMMDD-NNN` (например: АКТ-20260330-001)
- Счёт: `СЧ-YYYYMMDD-NNN` (например: СЧ-20260401-001)

## Деплой

Автоматический деплой через GitHub Actions (FTP на SpaceWeb) настроен в `.github/workflows/deploy.yml`. При пуше в `main` файлы автоматически загружаются на сервер.

Необходимые секреты в GitHub:
- `FTP_SERVER`
- `FTP_USERNAME`
- `FTP_PASSWORD`

## Cron-задачи

```
# Ежедневный отчёт админу в 9:00
0 9 * * * php /путь/к/проекту/admin_report.php

# Уведомления об истекающих договорах в 9:30
30 9 * * * php /путь/к/проекту/notify_expiry.php

# Очистка старых PDF в 3:00
0 3 * * * php /путь/к/проекту/cleanup.php
```

## Очистка старых PDF

Для автоматического удаления PDF старше 30 дней добавьте в cron:

```
0 3 * * * php /путь/к/проекту/cleanup.php
```

## Уведомления об истекающих договорах

Для ежедневных уведомлений о договорах, заканчивающихся в ближайшие 3 дня:

```
0 9 * * * php /путь/к/проекту/notify_expiry.php
```
